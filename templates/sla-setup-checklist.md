# SLA setup checklist

- [ ] Business hours calendars created (standard, extended, 24/7) and holiday schedules added
- [ ] SLA KPIs defined (First response by, Resolve by)
- [ ] SLA created per tier; SLA items with Applicable When / Success / Warning / Failure conditions
- [ ] Warning and failure actions configured (notification, flow, escalation)
- [ ] Pause conditions defined (e.g. status On Hold / Waiting for customer)
- [ ] SLA applied: entitlement or default SLA set
- [ ] SLA activated (remember: edits to active SLA items create active-layer changes)
- [ ] "Enable calendar export and import" turned on before exporting the solution
- [ ] Test cases for each tier: timer starts, warns, breaches, pauses
- [ ] SLAs added to the solution; deactivated before re-import into an org that already has them
